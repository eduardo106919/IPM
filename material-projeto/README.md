
# Material Projeto

Conteúdo:
- **Vue Maps**: demonstração da utilização da Google Maps API em conjunto com o Vue para criar mapas geográficos.
- **Vue Graphs**: demonstração da utilização da biblioteca chart.js em conjunto com o Vue para criar alguns gráficos de barras, linhas e pie.
- **[JSON Server](https://github.com/typicode/json-server)**: ferramenta para simular um servidor REST a partir de um ficheiro `db.json`.
- **Criar um ficheiro `db.json`**: pequeno script em Python para criar um ficheiro `db.json` a partir de um conjunto de ficheiros JSON e CSV.
